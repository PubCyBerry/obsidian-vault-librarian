# Shape Up

How Basecamp runs product work in six-week cycles.

## Takeaways so far
- Shape the work before you commit to it. Set the appetite first, meaning how much time the problem is worth, then find a solution that fits it.
- A betting table picks what goes into the next cycle. There is no backlog to groom.
- A team gets the whole cycle without interruptions, then a two-week cool-down.
- Hill charts show whether a piece of work is still uphill, being figured out, or downhill, being done.

## Questions
- Would six weeks work for a team of four? Maybe three.
