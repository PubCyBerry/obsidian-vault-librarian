# How this vault works

- Projects live in `Projects/<name>/`, each with a hub note named after the folder.
- Meeting notes live in `Meetings/` and are named `YYYY-MM-DD Title.md`.
- Action items are tasks with the owner in parentheses: `- [ ] Draft the FAQ (Sam)`.
- New notes without a clear home go to `Inbox/`.
- Write in plain English and short sentences.
- When you answer from the notes, cite the lines you used.
