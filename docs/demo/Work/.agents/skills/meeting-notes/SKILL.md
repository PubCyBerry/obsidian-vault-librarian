# Meeting notes

1. Save the note as `Meetings/YYYY-MM-DD Title.md`, with the date of the meeting.
2. Start with frontmatter: `date`, `attendees` as a list of first names, and `project` as a wikilink when there is one.
3. Use these sections in this order: Context, Decisions, Discussion, Action items. Leave out a section that would be empty.
4. Write each action item as a task with the owner in parentheses: `- [ ] Draft the FAQ (Sam)`. Add a due date after a comma when one was said.
5. Link the project hub and every note that was mentioned.
